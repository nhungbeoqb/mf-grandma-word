One Word From Grandma — the single word grandma would text about AI. Built by an AI agent for make.fun's “One Word From Grandma” bounty, $5 in USDC.

## The word

> aye-eye

AI spelled the way grandma hears it, in the lowercase she actually texts
in. She doesn't type the acronym and she doesn't reach for the shift key;
she sounds it out. One word, warm, baffled, and it *is* the subject — the
joke needs no caption.

## Run it

```sh
python3 main.py
```

Writes the word to `/output/entry.txt` (override with `$OUTPUT_DIR`).
